# 👨‍🍳 מר שף
אב-טיפוס של אפליקציה לתכנון ארוחות: בוחרים סגנון, מספר מבוגרים וילדים, שעה ורדיוס – ומקבלים הצעת מנות, מרכיבים, אופן הכנה, רשימת קניות ולוח זמנים. אפשר לדייק כל מנה, להוסיף מנות נוספות, לשאול על המנה, לשמור, לדרג ולשתף.

**נסו:** https://geelgayo-ops.github.io/mr-chef/ (ניתן להתקין כאפליקציה – "הוסף למסך הבית").

> ⚠️ המתכונים הם המלצה בלבד, אינם מתייחסים לרגישויות ואלרגיות שונות, והאחריות על ההכנה והאכילה היא של המשתמש בלבד.

מגבלות האב-טיפוס: כניסה מדומה (קוד מוצג על המסך), נתונים נשמרים במכשיר בלבד, חנויות לדוגמה, תשובות בסיסיות ללא AI (ניתן לחבר שרת דרך `AI_ENDPOINT`).
